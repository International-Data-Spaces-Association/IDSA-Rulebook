# IDSA Rulebook

## IDSA Rulebook 2026-3

The IDSA Rulebook sets out the principles and rules for trusted data sharing in data spaces. It distinguishes mandatory requirements from optional, value-adding practices and covers the functional, technical, operational and legal dimensions of creating and operating a data space. It helps data space initiatives define their rules, governance mechanisms and legal basis.

The Rulebook answers three questions: How is a data space set up? What must it include? How is it made trustworthy?

## Who should read it?

The Rulebook is written for data space initiatives, Data Space Governance Authorities (DSGAs), current and future data space participants, and anyone who wants to understand how data spaces work and how to set one up. Readers do not need a legal or software engineering background.

## How it relates to other IDSA documents

- The [IDS Reference Architecture Model (IDS-RAM)](https://kb.internationaldataspaces.org/external/ram/) is the main reference for implementing the Rulebook. It translates the Rulebook's governance models and requirements into logical components, interfaces and behaviour patterns.
- The [Dataspace Protocol (DSP)](https://eclipse-dataspace-protocol-base.github.io/DataspaceProtocol/) specifies the interoperable message exchanges for catalogue access, contract negotiation and data transfer that the Rulebook refers to.
- The [IDSA Glossary](https://kb.internationaldataspaces.org/external/glossary/) defines the terms used across IDSA documents.
